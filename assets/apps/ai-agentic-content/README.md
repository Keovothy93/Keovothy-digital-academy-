# Keovothy — Agentic AI Copywriter Website

A responsive SaaS-style copywriting workspace prototype built with plain HTML, CSS, and JavaScript.

## Included
- Overview dashboard
- Agentic AI Writer workflow
- Template library
- Brand Voice profile
- Saved Projects
- Analytics dashboard
- Settings with dark mode and compact sidebar
- Khmer / English / bilingual output modes
- Copy, save, export, search, localStorage persistence
- Responsive desktop, tablet, and mobile navigation

## Run locally
Open `index.html` directly in a modern browser, or serve the folder with any static server.

Example with Python:
```bash
python -m http.server 8080
```
Then open `http://localhost:8080`.

## Prototype note
The current generation engine is local/demo logic. It is intentionally not connected to an external AI API yet.
