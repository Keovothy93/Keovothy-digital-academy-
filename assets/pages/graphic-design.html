Core Principles

៦ ចំណុចដែលធ្វើឱ្យ Design មើលទៅមានភាពអាជីព

ចាប់ផ្តើមដោយការទំនាក់ទំនងឱ្យច្បាស់។ Decoration គឺជាផ្នែកបន្ទាប់ បន្ទាប់ពី Audience អាចមើលឃើញ និងយល់ Message សំខាន់បានភ្លាមៗ។

Visual Hierarchy

ធ្វើឱ្យ Headline ធំបំផុត បន្ទាប់មក Benefit, Supporting Text និង CTA តាមលំដាប់សារៈសំខាន់។

Grid & Alignment

តម្រឹមវត្ថុទៅតាម Grid ដូចគ្នា។ Alignment ល្អធ្វើឱ្យ Layout ស្អាត ទោះមានវត្ថុច្រើនក៏ដោយ។

Spacing

ប្រើចន្លោះទំនេរដើម្បីបំបែកក្រុមព័ត៌មាន និងផ្តល់ខ្យល់ឱ្យ Product, Model និង Headline។

Color

កំណត់ពណ៌ចម្បង ពណ៌ជំនួយ និង Accent។ ត្រួតពិនិត្យ Contrast ឱ្យអក្សរអានបានច្បាស់។

Typography

ប្រើ Font មិនច្រើនជាង ២ Family និងកំណត់ទំហំ Weight និង Line-height ឱ្យមានប្រព័ន្ធ។

Consistency

រក្សា Button, Icon, Radius, Shadow និង Style រូបភាពឱ្យដូចគ្នាទូទាំង Artwork ឬ Campaign។

01. សរសេរ Brief មុនចាប់ផ្តើម Design

កំណត់ Audience, Objective, Message, Size, Mandatory Elements និង Deadline។ Brief ច្បាស់ជួយកាត់បន្ថយការកែច្រើនដង។

02. រៀប Layout ជា Grayscale ជាមុន

ប្រើប្រអប់ពណ៌ប្រផេះសម្រាប់ Headline, Image, Product និង CTA ដើម្បីសាកល្បង Composition។ បើ Layout អានបានល្អដោយគ្មានពណ៌ នោះ Foundation រឹងមាំ។

03. បង្កើត Type Scale

ឧទាហរណ៍៖ Headline 48px/900, Supporting 24px/700, Body 16px/400 និង Caption 14px/500។ កុំប្រើទំហំខុសៗគ្នាដោយគ្មានហេតុផល។

04. ប្រើពណ៌តាមតួនាទី

Background ផ្តល់បរិយាកាស, Brand Color បញ្ជាក់អត្តសញ្ញាណ និង Accent Color នាំភ្នែកទៅ CTA។ សូមសាកល្បង Contrast ទាំងលើទូរសព្ទ និងកុំព្យូទ័រ។

05. ពិនិត្យនៅទំហំតូច

Zoom Out ឬមើល Artwork លើទូរសព្ទ។ បើ Headline, Product និង CTA នៅតែច្បាស់ នោះ Hierarchy ដំណើរការ។ ពិនិត្យអក្ខរាវិរុទ្ធ និង Margin មុន Export។
